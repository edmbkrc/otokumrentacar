# OTOKUM Rent A Car

Vite + React tabanlı OTOKUM Rent A Car web sitesi. Modern UI (Tailwind, Radix, Lucide) ve client-side routing (react-router) kullanır. Üretimde Vercel’e deploy edilir, domain yönetimi Cloudflare üzerindedir.

## Teknolojiler
- React 18, react-router-dom
- Vite
- TailwindCSS, Radix UI, Lucide
- Vercel (deploy), Cloudflare (DNS)

## Hızlı Başlangıç
```bash
npm install
npm run dev           # Geliştirme sunucusu (http://localhost:3000)
npm run build         # Üretim build’i (dist/)
npm run preview       # dist önizleme
